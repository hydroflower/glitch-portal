# Глитч портал

Эффект для TouchDesigner: включаешь камеру, поднимаешь руки, и между большими и указательными пальцами появляется глитч-окно. Трекинг рук на MediaPipe.

**Гайд:** открой страницу GitHub Pages этого репозитория (или `index.html`).

**Быстро:** перетащи `glitch_portal_setup.py` в TouchDesigner → правый клик по ноде → Run Script.
